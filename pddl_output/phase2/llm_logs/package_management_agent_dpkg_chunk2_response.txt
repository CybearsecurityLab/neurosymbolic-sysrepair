```lisp
(:predicates
  (file_exists ?f - filesystem_object))

(:action build-package
  :parameters (?dir - directory ?output - filesystem_object)
  :precondition (file_exists ?dir)
  :effect (file_exists ?output))

(:action extract-package
  :parameters (?package - package ?target - directory)
  :precondition (file_exists ?package)
  :effect (file_exists ?target))
```

**Explanation:**

1. **Predicates:**
   - `(file_exists ?f - filesystem_object)`: Indicates that a file or directory exists in the system.

2. **Actions:**
   - **`build-package`:**
     - **Parameters:** `?dir` (input directory) and `?output` (output archive/directory).
     - **Precondition:** The input directory `?dir` must exist.
     - **Effect:** After execution, the output `?output` (e.g., a new archive) exists.
   - **`extract-package`:**
     - **Parameters:** `?package` (package to extract) and `?target` (target directory).
     - **Precondition:** The package `?package` must exist.
     - **Effect:** After execution, the target directory `?target` (with extracted files) exists.

**Rationale:**
- The `build-package` action models the creation of an output file/directory from an existing input directory.
- The `extract-package` action assumes the target directory's existence is confirmed after extraction, leveraging the `file_exists` predicate to represent the state change. While this simplifies the modeling of individual files, it aligns with the provided predicates and captures the essential state transition.
