### Actions for `apt-get` Commands

#### **1. `update`**
- **Parameters**: `?sources_list` (configuration_file)
- **Preconditions**: 
  - `(file_exists ?sources_list)`
- **Effects**: 
  - `(package_index_updated ?sources_list)`

#### **2. `upgrade`**
- **Parameters**: `?p` (package)
- **Preconditions**: 
  - `(package_index_updated ?sources_list)`
  - `(package_installed ?p)`
- **Effects**: 
  - `(package_installed ?p)`  // Upgraded version remains installed

#### **3. `install`**
- **Parameters**: `?p` (package)
- **Preconditions**: 
  - `(not (package_installed ?p))`
  - `(file_exists ?sources_list)`
- **Effects**: 
  - `(package_installed ?p)`

#### **4. `remove`**
- **Parameters**: `?p` (package)
- **Preconditions**: 
  - `(package_installed ?p)`
- **Effects**: 
  - `(not (package_installed ?p))`

#### **5. `purge`**
- **Parameters**: `?p` (package)
- **Preconditions**: 
  - `(package_installed ?p)`
- **Effects**: 
  - `(not (package_installed ?p))`  // Configuration files also removed (modeled implicitly)

#### **6. `dist-upgrade`**
- **Parameters**: `?p` (package)
- **Preconditions**: 
  - `(package_index_updated ?sources_list)`
  - `(package_installed ?p)`
- **Effects**: 
  - `(not (package_installed ?p))`  // May remove packages due to dependency changes

#### **7. `reinstall`**
- **Parameters**: `?p` (package)
- **Preconditions**: 
  - `(package_installed ?p)`
- **Effects**: 
  - `(package_installed ?p)`  // Reinstalled (version may change)

#### **8. `source`**
- **Parameters**: `?s` (source_package)
- **Preconditions**: 
  - `(file_exists ?sources_list)`  // Requires deb-src in sources list
- **Effects**: 
  - `(source_package_downloaded ?s)`

#### **9. `build-dep`**
- **Parameters**: `?p` (package)
- **Preconditions**: 
  - `(depends_on ?p ?d)`  // Package `?p` depends on build dependency `?d`
  - `(not (package_installed ?d))`
- **Effects**: 
  - `(package_installed ?d)`

---

### **Predicates Used**
1. `(file_exists ?f)`  
   - Indicates a file (e.g., sources list) exists.
2. `(package_installed ?p)`  
   - Indicates a package is installed.
3. `(package_index_updated ?sources_list)`  
   - Indicates the package index is updated.
4. `(source_package_downloaded ?s)`  
   - Indicates a source package is downloaded.
5. `(depends_on ?p ?d)`  
   - Indicates package `?p` depends on package `?d`.

---

### **Notes**
- Actions like `dist-upgrade` and `purge` may involve removing packages, modeled via `(not (package_installed ?p))`.
- The `source` command assumes the presence of `deb-src` entries in the sources list.
- Dependencies are modeled using `(depends_on ?p ?d)` for build dependencies.
