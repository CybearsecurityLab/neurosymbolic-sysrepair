(define (problem copy-problem)
  (:domain file-operations)
  (:objects
    file1 file2 dir1 dir2 - filesystem_object
  )
  (:init
    (file_exists file1)
    (file_exists dir1)
    (not (file_exists file2))
    (not (file_exists dir2))
  )
  (:goal
    (and
      (file_exists file2)
      (hard_link_exists file2 file1)
      (file_exists dir2)
      (directory_exists dir2)
      (attributes_preserved dir2 dir1)
    )
  )
)

**Domain File (file-operations.pddl):**

```lisp
(define (domain file-operations)
  (:requirements :strips :typing)
  (:types
    filesystem_object
  )
  (:predicates
    (file_exists ?f - filesystem_object)
    (hard_link_exists ?dest ?src - filesystem_object)
    (symbolic_link_exists ?dest ?src - filesystem_object)
    (attributes_copied ?dest ?src - filesystem_object)
    (attributes_preserved ?dest ?src - filesystem_object)
    (reflink_exists ?dest ?src - filesystem_object)
    (directory_exists ?d - filesystem_object)
  )
  (:action copy-hard-link
    :parameters (?src ?dest - filesystem_object)
    :precondition (and (file_exists ?src) (not (file_exists ?dest)))
    :effect (and (file_exists ?dest) (hard_link_exists ?dest ?src))
  )
  (:action copy-symbolic-link
    :parameters (?src ?dest - filesystem_object)
    :precondition (and (file_exists ?src) (not (file_exists ?dest)))
    :effect (and (file_exists ?dest) (symbolic_link_exists ?dest ?src))
  )
  (:action copy-attributes-only
    :parameters (?src ?dest - filesystem_object)
    :precondition (and (file_exists ?src) (not (file_exists ?dest)))
    :effect (and (file_exists ?dest) (attributes_copied ?dest ?src))
  )
  (:action copy-recursive
    :parameters (?src ?dest - filesystem_object)
    :precondition (and (file_exists ?src) (not (file_exists ?dest)))
    :effect (and (file_exists ?dest) (directory_exists ?dest))
  )
  (:action copy-preserve-all
    :parameters (?src ?dest - filesystem_object)
    :precondition (and (file_exists ?src) (not (file_exists ?dest)))
    :effect (and (file_exists ?dest) (attributes_preserved ?dest ?src))
  )
  (:action copy-reflink
    :parameters (?src ?dest - filesystem_object)
    :precondition (and (file_exists ?src) (not (file_exists ?dest)))
    :effect (and (file_exists ?dest) (reflink_exists ?dest ?src))
  )
)
```

---

**Explanation:**

1. **Predicates:**
   - `file_exists`: Indicates a file/directory exists.
   - `hard_link_exists`, `symbolic_link_exists`, `reflink_exists`: Capture specific copy types.
   - `attributes_copied`, `attributes_preserved`: Model metadata preservation.
   - `directory_exists`: Used for recursive directory copying.

2. **Actions:**
   - **`copy-hard-link`**: Creates a hard link between source and destination.
   - **`copy-symbolic-link`**: Creates a symbolic link.
   - **`copy-attributes-only`**: Copies metadata without content.
   - **`copy-recursive`**: Recursively copies directories.
   - **`copy-preserve-all`**: Combines recursive copying and metadata preservation.
   - **`copy-reflink`**: Creates a copy-on-write (reflink) link.

3. **Problem File:**
   - Models a scenario where files and directories are copied with specific operations (e.g., hard links, recursive preservation).

This formalization captures key file operations described in the problem, using PDDL to model actions and their effects.
