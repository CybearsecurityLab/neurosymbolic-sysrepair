To model the behavior of the `ps` command's options for selecting processes based on user or terminal associations, we define new predicates and actions in PDDL. These actions represent the conditions under which a process is included in the output when using specific options.

---

### **New Predicates**
1. **`(process_exists ?p - process)`**  
   Indicates that a process `?p` exists.

2. **`(process_associated_with_terminal ?p - process ?t - terminal)`**  
   Indicates that process `?p` is associated with terminal `?t`.

3. **`(process_effective_user ?p - process ?u - user)`**  
   Indicates that the effective user of process `?p` is user `?u`.

4. **`(process_real_user ?p - process ?u - user)`**  
   Indicates that the real user of process `?p` is user `?u`.

---

### **Actions**

#### **1. Select Process by Terminal (`--tty`)**  
This action models the `--tty` option, which selects processes associated with a specific terminal.

```lisp
(:action select-process-by-terminal
    :parameters (?p - process ?t - terminal)
    :precondition (and 
        (interface_exists ?t) 
        (process_associated_with_terminal ?p ?t))
    :effect (selected-process ?p)
)
```

---

#### **2. Select Process by Effective User (`-u`, `--user`)**  
This action models options like `-u` or `--user`, which select processes by their effective user.

```lisp
(:action select-process-by-effective-user
    :parameters (?p - process ?u - user)
    :precondition (and 
        (process_exists ?p) 
        (process_effective_user ?p ?u))
    :effect (selected-process ?p)
)
```

---

#### **3. Select Process by Real User (`U`, `-U`)**  
This action models options like `U` or `-U`, which select processes by their real user.

```lisp
(:action select-process-by-real-user
    :parameters (?p - process ?u - user)
    :precondition (and 
        (process_exists ?p) 
        (process_real_user ?p ?u))
    :effect (selected-process ?p)
)
```

---

### **Explanation**
- **Predicates** define the state of the system (e.g., whether a process exists or is associated with a terminal).
- **Actions** represent the conditions under which a process is selected for display when using specific `ps` options.
- The `selected-process` effect is a placeholder to indicate that the process is included in the output, though it is not part of the original preferred predicates. This effect can be adjusted based on the modeling framework.

This structure allows reasoning about which processes are displayed under different `ps` options by checking the preconditions of the corresponding actions.
