```lisp
(:predicates
  (file_critical ?f - configuration_file)
  (file_readable ?f - configuration_file)
  (file_writable ?f - configuration_file)
  (file_owned_by ?f - configuration_file ?u - user)
  (sudoers_checked ?f - configuration_file)
  (strict_check_enabled)
  (include_editing_disabled)
  (owner_enforced ?f - configuration_file ?u - user)
  (perms_enforced ?f - configuration_file ?m - integer)
)

(:action check-sudoers
  :parameters (?f - configuration_file)
  :precondition (and (file_critical ?f) (file_readable ?f))
  :effect (and (sudoers_checked ?f)
               (forall (?f2 - configuration_file) 
                 (when (included_in ?f ?f2) (sudoers_checked ?f2)))
               (if (not (file_owned_by ?f ?u - user)) 
                   (not (sudoers_checked ?f)))
               (if (not (file_writable ?f)) 
                   (not (sudoers_checked ?f))))
)

(:action enforce-sudoers-owner
  :parameters (?f - configuration_file ?u - user)
  :precondition (and (file_critical ?f) (user_exists ?u))
  :effect (and (file_owned_by ?f ?u) (owner_enforced ?f ?u))
)

(:action enforce-sudoers-perms
  :parameters (?f - configuration_file ?m - integer)
  :precondition (file_critical ?f)
  :effect (and (file_permissions ?f ?m) (perms_enforced ?f ?m))
)

(:action enable-strict-checking
  :precondition (not strict_check_enabled)
  :effect (strict_check_enabled)
)

(:action disable-include-editing
  :precondition (not include_editing_disabled)
  :effect (include_editing_disabled)
)
```

**Explanation of Key Design Choices:**

1. **Predicates Selection:**
   - Used `file_critical` to represent the special security status of sudoers files
   - `file_readable`/`file_writable` for access control checks
   - `file_owned_by` to track ownership validation
   - `sudoers_checked` to represent successful syntax validation
   - `strict_check_enabled`/`include_editing_disabled` for mode flags

2. **Action Design:**
   - `check-sudoers` handles the -c option with cascading checks for included files
   - `enforce-sudoers-owner`/-`perms` implement -O/-P options with ownership/permission enforcement
   - `enable-strict-checking`/-`disable-include-editing` represent -s/-I flags

3. **Complex Effects:**
   - The `check-sudoers` action includes conditional effects for ownership/permission validation
   - Universal quantification (`forall`) handles included files as described in the documentation

4. **Parameter Design:**
   - Configuration files and users are explicit parameters
   - Integer parameter for file permissions (octal mode)

This design captures the core functionality of visudo's command-line options while adhering to the PDDL syntax and the specified constraints.
