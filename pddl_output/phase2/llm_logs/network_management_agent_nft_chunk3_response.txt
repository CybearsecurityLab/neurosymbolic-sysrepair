```pddl
(define (problem firewall-configuration)
  (:domain firewall)
  (:objects
    set1 - firewall_rule
    set2 - firewall_rule
    map1 - firewall_rule
    map2 - firewall_rule
  )
  (:init
    (not (firewall_rule_exists set1))
    (not (firewall_rule_exists set2))
    (not (firewall_rule_exists map1))
    (not (firewall_rule_exists map2))
  )
  (:goal
    (and
      (firewall_rule_exists set1)
      (firewall_rule_exists map1)
      (not (firewall_rule_exists set2))
      (not (firewall_rule_exists map2))
    )
  )
)

(define (domain firewall)
  (:requirements :strips)
  (:predicates
    (firewall_rule_exists ?r - firewall_rule)
  )
  (:action add-set
    :parameters (?r - firewall_rule)
    :precondition (not (firewall_rule_exists ?r))
    :effect (firewall_rule_exists ?r)
  )
  (:action delete-set
    :parameters (?r - firewall_rule)
    :precondition (firewall_rule_exists ?r)
    :effect (not (firewall_rule_exists ?r))
  )
  (:action destroy-set
    :parameters (?r - firewall_rule)
    :precondition (firewall_rule_exists ?r)
    :effect (not (firewall_rule_exists ?r))
  )
  (:action add-map
    :parameters (?r - firewall_rule)
    :precondition (not (firewall_rule_exists ?r))
    :effect (firewall_rule_exists ?r)
  )
  (:action delete-map
    :parameters (?r - firewall_rule)
    :precondition (firewall_rule_exists ?r)
    :effect (not (firewall_rule_exists ?r))
  )
  (:action destroy-map
    :parameters (?r - firewall_rule)
    :precondition (firewall_rule_exists ?r)
    :effect (not (firewall_rule_exists ?r))
  )
)
```

**Explanation:**

- **Domain Definition:** The domain defines actions for managing firewall rules (sets and maps) using the `firewall_rule_exists` predicate. Each action (add/delete/destroy) for sets and maps modifies the existence of a `firewall_rule`.
- **Problem Definition:** The problem specifies initial states where certain rules do not exist and a goal state where specific rules are added and others removed.
- **Actions:** 
  - `add-set`/`add-map`: Create a new firewall rule (set/map).
  - `delete-set`/`delete-map`: Remove an existing rule.
  - `destroy-set`/`destroy-map`: Remove a rule if it exists (modeled similarly to delete due to PDDL constraints).
- **Limitations:** Element-level operations (add/delete elements in sets/maps) are not modeled due to lack of specific predicates in the provided schema.
