### Domain Actions and Predicates for Useradd Configuration

#### **Predicates**
1. **`file_exists(?f - file)`**  
   Indicates that the file `?f` exists.

2. **`configures(?cf - configuration_file, ?s - service)`**  
   Indicates that the configuration file `?cf` is configured for the service `?s`.

3. **`group_exists(?g - group)`**  
   Indicates that the group `?g` exists.

4. **`selinux_user_set(?u - user, ?seuser - string)`**  
   Indicates that the SELinux user `?seuser` is set for the user `?u`.

---

#### **Actions**

1. **`set_default_shell`**  
   **Parameters**:  
   - `?shell_path - file` (e.g., `/bin/bash`)  
   - `?service - service` (e.g., `useradd_service`)  
   - `?cf - configuration_file` (e.g., `useradd_config`)  

   **Preconditions**:  
   - `(file_exists ?shell_path)`  

   **Effect**:  
   - `(configures ?cf ?service)`  

   **Description**:  
   Sets the default shell for new users in the configuration file `?cf` for the service `?service`.

---

2. **`set_default_home_base`**  
   **Parameters**:  
   - `?base_dir - file` (e.g., `/home`)  
   - `?service - service`  
   - `?cf - configuration_file`  

   **Preconditions**:  
   - `(file_exists ?base_dir)`  

   **Effect**:  
   - `(configures ?cf ?service)`  

   **Description**:  
   Sets the base directory for home directories in the configuration file `?cf` for the service `?service`.

---

3. **`set_default_primary_group`**  
   **Parameters**:  
   - `?group - group` (e.g., `users`)  
   - `?service - service`  
   - `?cf - configuration_file`  

   **Preconditions**:  
   - `(group_exists ?group)`  

   **Effect**:  
   - `(configures ?cf ?service)`  

   **Description**:  
   Sets the default primary group for new users in the configuration file `?cf` for the service `?service`.

---

4. **`set_default_expire_date`**  
   **Parameters**:  
   - `?expire_date - string` (e.g., `2025-12-31`)  
   - `?service - service`  
   - `?cf - configuration_file`  

   **Effect**:  
   - `(configures ?cf ?service)`  

   **Description**:  
   Sets the default expiration date
