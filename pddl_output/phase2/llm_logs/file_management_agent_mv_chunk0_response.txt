To model the behavior of the `mv` command in a PDDL-like planning domain, we can define actions that capture the core functionalities of moving files, including basic moves, forced overwrites, and moving files into directories. Additionally, we introduce necessary predicates to represent the state of the file system.

---

### **Predicates**

1. **`(file_exists ?f - file)`**  
   Indicates that the file `?f` exists in the file system.

2. **`(is-directory ?f - file)`**  
   Indicates that the file `?f` is a directory.

---

### **Actions**

#### **1. `move-file`**  
This action moves a file from a source to a destination **only if the destination does not already exist**.

```lisp
(:action move-file
  :parameters (?source - file ?destination - file)
  :precondition (and (file_exists ?source) (not (file_exists ?destination)))
  :effect (and (not (file_exists ?source)) (file_exists ?destination))
)
```

---

#### **2. `move-file-force`**  
This action moves a file from a source to a destination, **overwriting the destination if it exists**.

```lisp
(:action move-file-force
  :parameters (?source - file ?destination - file)
  :precondition (file_exists ?source)
  :effect (and (not (file_exists ?source)) (file_exists ?destination))
)
```

---

#### **3. `move-to-directory`**  
This action moves a file into a directory. It assumes the directory exists and is a valid target.

```lisp
(:action move-to-directory
  :parameters (?source - file ?directory - file)
  :precondition (and (file_exists ?source) (file_exists ?directory) (is-directory ?directory))
  :effect (and (not (file_exists ?source)) (file_exists ?source))
)
```

> **Note**: The effect here is simplified. In a real system, the file would be moved into the directory, and its path would change. However, without a path-based representation, we assume that the file still exists under the same name but in a different location. A more precise model would require additional predicates or functions to track file paths.

---

### **Summary**

- **`move-file`**: Moves a file when the destination is empty.
- **`move-file-force`**: Overwrites the destination file.
- **`move-to-directory`**: Moves a file into a directory.
