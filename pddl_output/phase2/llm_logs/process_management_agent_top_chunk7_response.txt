Since PDDL does not support conditional effects directly without additional constructs, we model each action as toggling a binary state by removing the current predicate and adding its opposite. ### **Predicates**
These predicates represent the current state of the display settings:

1. **`cpu-display-mode-single`**  
   - True if the CPU display is in "single mode" (combined view).
   - False if in "separate mode" (individual view).

2. **`numa-node-summary-enabled`**  
   - True if the NUMA node summary is enabled.
   - False if the CPU summary is shown.

3. **`column-justification-numeric-left`**  
   - True if numeric columns are left-justified.
   - False if right-justified.

4. **`column-justification-text-left`**  
   - True if text columns are left-justified.
   - False if right-justified.

5. **`bold-mode-enabled`**  
   - True if bold text is enabled.
   - False otherwise.

6. **`column-highlighting-enabled`**  
   - True if column highlighting is active.
   - False otherwise.

7. **`row-highlighting-enabled`**  
   - True if row highlighting is active.
   - False otherwise.

8. **`color-mode-enabled`**  
   - True if color display is enabled.
   - False if monochrome.

9. **`command-line-display-enabled`**  
   - True if command-line display is shown.
   - False if only process names are shown.

10. **`parent-focus-enabled`**  
    - True if parent process focus is enabled.
    - False otherwise.

11. **`field-management-enabled`**  
    - True if field management is active.
    - False otherwise.
