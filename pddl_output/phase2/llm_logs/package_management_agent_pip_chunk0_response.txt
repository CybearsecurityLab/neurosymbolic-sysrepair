### **1. Install a Package**
```lisp
(:action install-package
 :parameters (?p - package ?s - filesystem_object)
 :precondition (and (file_exists ?s) (not (package_installed ?p)))
 :effect (package_installed ?p))
```
**Description**: Installs a package from a source (e.g., local path, URL, or configuration file). Requires the source to exist and the package to not be installed.

**Description**: Creates a requirements file listing installed packages. Requires the file to be non-existent and writable.

### **5. Build a Wheel**
```lisp
(:action build-wheel
 :parameters (?p - package ?w - filesystem_object)
 :precondition (and (package_installed ?p) (not (file_exists ?w)) (file_writable ?w))

```
**Description**: Builds a wheel file for an installed package. Requires the package to be installed and the output file to be non-existent and writable.
