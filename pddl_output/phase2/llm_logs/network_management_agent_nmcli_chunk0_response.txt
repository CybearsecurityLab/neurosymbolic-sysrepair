```lisp
(define (domain network-configuration)
  (:requirements :strips :typing)
  (:types 
    service 
    configuration-file 
    user
  )
  (:predicates
    (can_escalate ?u - user)
    (file_exists ?f - configuration-file)
    (file_writable ?f - configuration-file)
    (config_applied ?s - service)
  )
  (:action change-hostname
    :parameters (?u - user ?f - configuration-file ?s - service)
    :precondition (and (can_escalate ?u) (file_exists ?f) (file_writable ?f))
    :effect (config_applied ?s)
  )
  (:action reload-configuration
    :parameters (?s - service)
    :precondition (config_applied ?s)
    :effect (config_applied ?s)
  )
  (:action update-dns-rc
    :parameters (?f - configuration-file)
    :precondition (file_exists ?f)
    :effect (file_exists ?f)
  )
  (:action restart-dns-plugin
    :parameters (?s - service)
    :precondition (config_applied ?s)
    :effect (config_applied ?s)
  )
)
```

**Explanation:**

1. **Domain Definition**:  
   - **Types**: `service`, `configuration-file`, and `user` are defined to categorize entities.
   - **Predicates**:  
     - `can_escalate`: Indicates a user has permission to perform privileged actions.  
     - `file_exists`/`file_writable`: Tracks the state of configuration files.  
     - `config_applied`: Marks a service configuration as applied.

2. **Actions**:  
   - **`change-hostname`**:  
     - **Parameters**: User, hostname file (e.g., `/etc/hostname`), and service (e.g., `network-manager`).  
     - **Preconditions**: Requires user privilege escalation and file writability.  
     - **Effect**: Marks the service configuration as applied.  

   - **`reload-configuration`**:  
     - **Parameters**: Service (e.g., `network-manager`).  
     - **Precondition/Effect**: Ensures the service configuration is reapplied.  

   - **`update-dns-rc`**:  
     - **Parameters**: DNS configuration file (e.g., `/etc/resolv.conf`).  
     - **Precondition/Effect**: Ensures the file exists (assumed to be pre-configured).  

   - **`restart-dns-plugin`**:  
     - **Parameters**: Service (e.g., `dns-plugin`).  
     - **Precondition/Effect**: Reapplies the service configuration after a restart.  

**Key Assumptions**:  
- The hostname file (`/etc/hostname`) and DNS config file (`/etc/resolv.conf`) are modeled as `configuration-file` types.  
- The `config_applied` predicate is reused to represent successful configuration changes for services like `network-manager` and `dns-plugin`.  
- File operations (e.g., writability) are preconditions for actions modifying system settings.
