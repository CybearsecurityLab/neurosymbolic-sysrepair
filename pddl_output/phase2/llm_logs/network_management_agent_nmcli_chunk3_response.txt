```lisp
(:predicates
  (interface_exists ?i - interface)
  (device_connected ?i - interface)
  (device_managed ?i - interface)
  (wifi_connected ?i - interface)
  (hotspot_active ?i - interface)
  (checkpoint_created ?i - interface)
  (config_modified ?i - interface))

(:action connect_device
  :parameters (?i - interface)
  :precondition (and (interface_exists ?i) (device_managed ?i))
  :effect (device_connected ?i))

(:action disconnect_device
  :parameters (?i - interface)
  :precondition (device_connected ?i)
  :effect (not (device_connected ?i)))

(:action set_device_managed
  :parameters (?i - interface ?m - boolean)
  :precondition (interface_exists ?i)
  :effect (device_managed ?i))

(:action modify_device_config
  :parameters (?i - interface)
  :precondition (and (interface_exists ?i) (device_connected ?i))
  :effect (config_modified ?i))

(:action create_wifi_connection
  :parameters (?i - interface ?ssid - string ?password - string)
  :precondition (interface_exists ?i)
  :effect (wifi_connected ?i))

(:action create_hotspot
  :parameters (?i - interface ?ssid - string ?password - string)
  :precondition (interface_exists ?i)
  :effect (hotspot_active ?i))

(:action take_checkpoint
  :parameters (?i - interface)
  :precondition (interface_exists ?i)
  :effect (checkpoint_created ?i))
```

**Explanation:**  
- **Predicates** are defined to capture device states (connected, managed, WiFi/hotspot status) and configuration changes.  
- **Actions** map directly to nmcli commands:  
  - `connect_device`/`disconnect_device` handle device activation/deactivation.  
  - `set_device_managed` adjusts NetworkManager's control over the device.  
  - `modify_device_config` reflects temporary runtime changes.  
  - `create_wifi_connection`/`create_hotspot` manage wireless connectivity.  
  - `take_checkpoint` ensures configuration rollbacks for safety.  
- All actions use existing or newly defined predicates to align with the task constraints and preferred syntax.
